# Bright-Coffee-Shop-Analysis

# 1. PROJECT OVERVIEW

In this project I analyse sales over six months that the coffee shop has made to find insights and make recommendations where needed. The coffee shop has apoointed a new COE of whom I will be presenting the insights to so he can make informeed decisions going on forward.

My role is to apply Sequal Query Language (SQL), aggregated data, and visualization skills to evaluate revenue performance, identify sales patterns, and recommend actions to improve business outcomes.

# 2. OBJECTION

Using the given dataset, I am providing solutions to the following key questions:

Which products generate the highest revenue?
What time(s) of day drive the most sales activity?
How do sales vary across product categories and time intervals?
What recommendations can improve revenue growth and product performance
